# Add Email Support

![Email Support](images/email_support/email.jpg)

This chapter is dedicated to a new feature common in most web applications, the sending of emails. Under what circumstances would you want your application to send an email? There may be many. In this chapter, we will limit the scope of the question to user authentication. We are going to learn how we can add a password reset feature in the event our users forget their passwords. In search a case, the application will send an email with a specially put together link. The user can click on this link to have access to a password-reset form.email
